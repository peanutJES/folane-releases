# Folane 받기

Folane(폴레인)의 설치 파일을 올려 두는 곳이에요. 밑줄·찾아보기·메모 칸·AI·문서 번역을 갖춘 맥·윈도우 PDF 리더예요. 여기에는 판마다 설치 파일과 바뀐 내용만 있어요.

**[최신 판 받기 →](../../releases/latest)**

| 기기 | 파일 |
|---|---|
| 맥 (macOS 11 이상) | `Folane-<판>-mac.dmg` |
| 윈도우 설치판 (권장) | `Folane-Setup-<판>.exe` |
| 윈도우 휴대용 | `Folane-Portable-<판>.exe` |

1.9.2부터는 앱이 이 저장소의 새 판을 스스로 찾아요. 맥과 윈도우 설치판은 새 판을 받아 두었다가 앱을 끌 때 바꾸고, 윈도우 휴대용은 새 판이 나왔다고 알려 줘요. 이 확인 때 앱은 판 번호와 설치 파일만 받아 오고, 문서나 기록은 보내지 않아요.
