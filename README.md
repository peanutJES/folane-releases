<h1 align="center">Folane 받기</h1>

<p align="center">밑줄을 긋고, 모르는 말은 AI와 백과사전으로 바로 찾아보고, 나만의 메모는 옆 칸에 펼쳐 두는 PDF 리더<br>macOS · Windows</p>

---

Folane(폴레인)의 설치 파일과 업데이트 내역을 올려 두는 곳이에요. 이름은 folio(책·원고의 낱장)와 lane(길)을 합쳐 만들었고, ‘페이지를 따라가는 길’이라는 뜻이에요.

## 다운로드

**[최신 판 받기 →](../../releases/latest)**

| 기기 | 파일 | 필요한 것 |
|---|---|---|
| 맥 | `Folane-<판>-mac.dmg` | macOS 11(빅서) 이상, 애플 실리콘·인텔 |
| 윈도우 (설치판, 권장) | `Folane-Setup-<판>.exe` | 윈도우 10·11, 64비트 |
| 윈도우 (휴대용, 설치 없이 실행) | `Folane-Portable-<판>.exe` | 윈도우 10·11, 64비트 |

`latest-mac.json`, `latest.yml`, `.blockmap`은 앱이 업데이트를 확인할 때 읽는 파일이라 받지 않아도 돼요.

### 처음 설치할 때

개인이 만든 앱이라 Apple 공증이나 윈도우 코드 서명을 받지 않았어요. 그래서 처음 한 번은 확인 창이 떠요.

- **맥**: DMG를 열고 Folane을 Applications(응용 프로그램) 폴더로 끌어다 놓아요. 처음 열 때 “Apple에서 확인할 수 없습니다”가 뜨면 ‘완료’를 누르고 **시스템 설정 → 개인정보 보호 및 보안**에서 ‘그래도 열기’를 눌러요. macOS 14 이하는 응용 프로그램에서 Folane을 Control-클릭 → ‘열기’로 열어요.
- **윈도우**: SmartScreen이 막으면 **추가 정보 → 실행**을 눌러요.

### 업데이트

1.9.2부터는 Folane이 새 판을 스스로 찾아요. 켠 뒤 10초쯤 지나서, 그리고 켜 둔 동안 6시간마다 이 저장소의 최신 판을 확인해요.

- 맥·윈도우 설치판: 새 판을 뒤에서 받아 두고 ‘다시 켜서 업데이트’를 물어요. ‘나중에’를 누르면 Folane을 끌 때 바뀌어요.
- 윈도우 휴대용: 새 판이 나왔다고 알리고 이 페이지를 열어 줘요.
- 기다리지 않고 바로 보려면 ‘업데이트 확인…’을 눌러요(맥은 Folane 메뉴, 윈도우는 도움말 메뉴와 툴바 ⋯ 메뉴).
- 확인할 때 앱은 판 정보와 설치 파일만 받아 오고, 문서나 사용 기록은 보내지 않아요.
- 1.9.1 이하에는 이 기능이 없어서, 1.9.2 이상은 한 번 직접 받아 설치해야 해요.

## 업데이트 내역

판마다 자세한 내용은 [Releases](../../releases)에 있어요.

- **1.9.2** — 새 판을 스스로 찾아 받아요(맥·윈도우 설치판은 자동 업데이트, 윈도우 휴대용은 알림). 윈도우 툴바에서 켜진 도구(하이라이트·밑줄·취소선 등)를 진한 바탕과 테두리로 또렷하게 보여 줘요.
- **1.9.1** (맥) — 첫 배포판.

## 할 수 있는 것

- 하이라이트·밑줄·취소선, 펜(꾹 누르면 반듯한 직선)과 자, 한 쪽씩·두 쪽씩 보기
- 낱말에 밑줄을 그으면 위키백과 설명이 오른쪽 메모 칸에 펼쳐져요
- 메모는 표시한 줄 높이에 맞춰 오른쪽 칸에 늘 펼쳐져 있어서 본문을 가리지 않아요
- 인공지능에 물어보기(Gemini·ChatGPT·Claude 키, 내 컴퓨터 모델, 맥은 Apple Intelligence)
- 고른 글 번역, 원문 배치를 살린 문서 번역
- 지우개: 다른 앱이 남긴 주석, 인쇄하며 굳은 밑줄·하이라이트·서명까지 지워요
- 이미지·서명 넣기, 스캔한 PDF 글자 인식, 내 라이브러리
- 표시와 메모는 표준 PDF 주석으로 저장돼서 다른 PDF 앱에서도 보여요
